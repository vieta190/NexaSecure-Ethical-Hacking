# Day 2: Networking Basics

## Core Concepts
* **TCP/IP Model:** Application, Transport, Internet, and Network Access layers.
* **DNS:** Hostname-to-IP resolution using A, AAAA, CNAME, MX, and TXT records.
* **HTTP/HTTPS:** Request methods/headers and response status codes.

## Essential Ports

| Port | Service | Protocol | Notes |
| :--- | :--- | :--- | :--- |
| **21** | FTP | TCP | Cleartext credentials |
| **22** | SSH | TCP | Encrypted terminal access |
| **53** | DNS | UDP/TCP | Name resolution |
| **80** | HTTP | TCP | Web traffic |
| **443** | HTTPS | TCP | Encrypted Web traffic (TLS) |
